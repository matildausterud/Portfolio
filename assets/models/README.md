Place the exported web model here:

- Source Blender file: `synthwave-bird.blend`
- Web model expected by the portfolio: `synthwave-bird.glb`

Open the `.blend` file in Blender, then export as:

File > Export > glTF 2.0 > Format: GLB > `assets/models/synthwave-bird.glb`

The current homepage uses a handmade light-pink animated Three.js bird in `bird.js`. If you later export this Blender model as GLB, it can replace the handmade bird.
