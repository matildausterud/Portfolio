Från information till interaktion

Hur kan ett statiskt rådgivarverktyg bli ett flexibelt stöd för kundmötet?

Roll
Produktdesign, UX, struktur och prototypande i ett tvärfunktionellt team.
Tid
Sex månader med nästa version av Behovsguiden.
Fokus
Ett gemensamt arbetssätt för rådgivarna och en bättre dialog om kundens behov.

Bakgrund

Det här var ett sex månader långt projekt där vi tog fram nästa version av Behovsguiden, ett verktyg som används av Länsförsäkringars rådgivare i kundmötet.

Jag arbetade i ett tvärfunktionellt team med UX, produkt och utveckling, tillsammans med två representanter från bankverksamheten som bidrog med verksamhetsperspektiv och gemensamma arbetssätt för rådgivarna.

Målet var att skapa ett verktyg som både stärker kundmötet och skapar ett gemensamt arbetssätt för rådgivarna.

Problemet

Behovsguiden var främst utformad för att presentera information. Men rådgivarna behövde kunna förklara, visualisera och räkna tillsammans med kunden för att skapa förståelse, intresse och förtroende.

När verktyget inte räckte till skapade rådgivarna egna lösningar, till exempel Excel-kalkyler, PowerPoints och externa webbplatser.

  • För rådgivaren: verktyget gav inte tillräckligt stöd för att skapa ett värdefullt kundmöte.
  • För Länsförsäkringar: kundupplevelsen blev olika beroende på rådgivare och delar av mötet flyttade utanför de egna verktygen.

Lösning

Prototypen samlar information, interaktion och rådgivning i samma flöde. Rådgivaren kan visa sammanhang, räkna på sparande och föra samtalet vidare utan att lämna verktyget.

Resultatet blir ett tydligare stöd i kundmötet och en mer sammanhållen digital upplevelse.
